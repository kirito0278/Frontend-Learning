JS is a scripting language [A scripting language is a type of programming language designed to automate tasks, control existing software, and run without a manual compilation step. Instead of converting code into a standalone executable file beforehand like compiled languages do, scripting languages rely on an interpreter to translate and execute code line-by-line in real-time.]

A style sheet language is a computer language used to express the visual presentation and layout of structured documents like HTML. The primary and most widely used styling language on the web is Cascading Style Sheets (CSS), which controls colors, fonts, spacing, and responsive design.

A markup language is a system of symbols or tags added to a text document. It defines the structure, layout, and meaning of the content so a computer or web browser knows how to display or process it. It is not a programming language because it does not perform logic or calculations
